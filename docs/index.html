Módulo de ventas

Registrá ventas en segundos

Interface diseñada para que el cajero trabaje rápido, sin errores y sin necesidad de capacitación larga.

🔍

Tres formas de agregar productos

Se adapta a cualquier flujo de trabajo del negocio.

  • Escáner de código de barras — pistola USB o manual, reconocimiento instantáneo
  • Búsqueda por nombre — escribís las primeras letras y aparece el producto
  • Calculadora manual — para carnicería (código 930) y fiambrería (código 1003) con precio variable
  • Balanza Coura — lee automáticamente el código EAN-13 que genera la balanza con el peso incluido
💳

Múltiples formas de cobro

El cliente paga como quiere, el sistema registra todo correctamente.

  • Efectivo — calcula el vuelto automáticamente
  • Tarjeta / QR / transferencia — registrado por separado para el cierre de caja
  • Cuenta corriente (fiado) — se anota directo a la cuenta del cliente
  • Descuento en porcentaje — aplicable por venta
  • Cupón de descuento — monto fijo descontado del total
🧾

Ticket por WhatsApp al cliente

Al terminar cada venta, podés enviar el detalle completo al celular del cliente.

  • Lista de productos con cantidades y precios
  • Total, método de pago y vuelto
  • Descuentos aplicados
  • Se abre WhatsApp listo para enviar con un toque
  • El cajero elige si lo manda o no — no es obligatorio
⚡

Velocidad y comodidad para el cajero

Pensado para reducir el tiempo de atención en cada cliente.

  • Enter para confirmar la venta sin usar el mouse
  • El cursor cae automáticamente en el campo de importe recibido
  • Calculadora de vuelto en tiempo real mientras tipea
  • Pantalla limpia y legible para usar todo el día

Control de caja

La caja exacta, turno a turno

El módulo más crítico del sistema. Diseñado para detectar cualquier diferencia de dinero al instante.

Fórmula automática de cierre

El sistema calcula lo que tiene que haber en caja y lo compara con lo que declaró el cajero.

Apertura + Ventas en efectivo + Aportes de caja − Gastos registrados = Efectivo esperado Diferencia = Declarado − Esperado
Apertura de turno Cierre con declaración Diferencia al instante

Fiados y cuentas corrientes

Llevá los fiados sin papeles ni cuadernos

Todo digitalizado. Sabés en todo momento quién te debe, cuánto y hace cuánto.

📒

Registro completo por cliente

  • Cada cliente tiene su propia cuenta con historial completo
  • Podés anotar un fiado directamente al cerrar una venta
  • También podés anotarlo manualmente con descripción libre
  • Registro de cobros parciales o totales
  • Saldo pendiente siempre visible
📅

Vista de fiados por período

  • Filtrá los fiados por cualquier rango de fechas (Desde / Hasta)
  • Total fiado, total cobrado y total pendiente en el período
  • Tabla con nombre del cliente, monto y estado
  • Botón WhatsApp directo por cada fiado para recordar el cobro
📲

WhatsApp integrado para cobrar fiados

Con un solo toque podés contactar al cliente para avisarle que tiene deuda pendiente.

  • Si el fiado viene de una venta → manda el ticket completo con el detalle de lo que llevó
  • Si es un fiado manual → manda un recordatorio con el monto y tu nombre de negocio
  • El mensaje se abre en WhatsApp listo para enviar
  • Incluye el nombre del cliente y el monto adeudado
  • No necesitás buscar el número — ya está guardado en el sistema
